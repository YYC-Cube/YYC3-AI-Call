## 🔌 三、API端点完整清单

### 3.1 AI Family API

```
GET  /api/v1/ai-family?action=agents        # 获取所有Agent快照
GET  /api/v1/ai-family?action=metrics        # 获取系统指标
GET  /api/v1/ai-family?action=queue          # 获取任务队列状态
GET  /api/v1/ai-family?action=agent&id=:id   # 获取指定Agent详情

POST /api/v1/ai-family                       # 执行操作
  ├─ action: initialize                      # 初始化AI Family
  ├─ action: create-task                     # 创建新任务
  ├─ action: submit-task                     # 提交任务执行
  ├─ action: recommend-agents                # 推荐适合的Agent
  ├─ action: collaborate                     # 启动协作会话
  └─ action: update-config                   # 更新Agent配置
```

### 3.2 Multimodal API

```
POST /api/v1/multimodal/image/analyze       # 图像分析（支持多任务）
POST /api/v1/multimodal/audio/transcribe    # 音频转录
POST /api/v1/multimodal/audio/synthesize    # 语音合成
POST /api/v1/multimodal/document/extract    # 文档提取
POST /api/v1/multimodal/document/summarize  # 文档摘要
```

### 3.3 MCP API

```
GET  /api/v1/mcp/tools                       # 列出可用工具
GET  /api/v1/mcp/resources                   # 列出可用资源
POST /api/v1/mcp/tools/:name/call            # 调用指定工具
GET  /api/v1/mcp/resources/:uri/read         # 读取资源内容
```

### 3.4 Auth API

```
POST /api/v1/auth/login                      # 用户登录认证
POST /api/v1/auth/logout                     # 用户登出
POST /api/v1/auth/refresh                    # 刷新Token
```
