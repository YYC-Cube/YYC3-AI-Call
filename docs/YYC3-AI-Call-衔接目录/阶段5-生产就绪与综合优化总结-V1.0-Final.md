## 🛡️ Phase 5.3: 安全加固与审计

### 核心目标
构建7层纵深防御体系，满足OWASP Top 10安全要求。

### 交付清单

#### 安全中间件系统
**文件**: [lib/security/middleware.ts](../lib/security/middleware.ts)

**7层防护架构**:

```
┌─────────────────────────────────────┐
│ 第1层: CORS白名单                    │ ← 域名控制
├─────────────────────────────────────┤
│ 第2层: 速率限制                      │ ← DDoS防护
│   Redis滑动窗口算法                  │   API: 10r/s
│                                     │   General: 30r/s
├─────────────────────────────────────┤
│ 第3层: CSRF令牌                     │ ← 跨站伪造防护
│   Token生成/验证/Cookie设置          │
├─────────────────────────────────────┤
│ 第4层: 输入验证                      │ ← 注入防护
│   Zod schema强类型校验               │
│   预定义通用schema库                 │
├─────────────────────────────────────┤
│ 第5层: XSS输出编码                   │ ← 跨站脚本防护
│   HTML实体编码（零依赖）             │
│   递归对象消毒                       │
├─────────────────────────────────────┤
│ 第6层: 安全响应头                    │ ← 浏览器防护
│   HSTS/CSP/X-Frame-Options          │
│   X-Content-Type-Options            │
├─────────────────────────────────────┤
│ 第7层: 综合检查中间件                │ ← 一站式防护
│   runSecurityChecks()               │
│   自动执行上述6层检查                │
└─────────────────────────────────────┘
```

**预定义Schema库**:

```typescript
// UUID验证
commonSchemas.uuid

// 分页参数
commonSchemas.pagination  // { page, limit }

// 客户ID查询
commonSchemas.customerId  // { customerId: uuid }

// 通话记录查询
commonSchemas.callQuery   // { status?, startDate?, endDate?, pagination }

// AI对话消息
commonSchemas.aiMessage   // { message, sessionId?, context? }

// 文件上传元数据
commonSchemas.fileMetadata // { filename, mimetype, size }
```

**使用示例**:
```typescript
import { runSecurityChecks, commonSchemas } from '@/lib/security/middleware';

export async function POST(request: NextRequest) {
  // 一站式安全检查
  const { authorized, response, validatedData } = await runSecurityChecks(request, {
    requireCSRF: true,
    enableRateLimit: true,
    validateInput: commonSchemas.aiMessage,
  });

  if (!authorized) return response!;

  // 业务逻辑（validatedData已验证通过）
  const { message, sessionId } = validatedData as AiMessageInput;
  
  return NextResponse.json({ success: true });
}
```

**安全配置项**:
```typescript
const DEFAULT_CONFIG = {
  rateLimit: {
    windowMs: 900000,      // 15分钟窗口
    maxRequests: 100,      // 每15分钟100次请求
  },
  csrf: {
    enabled: true,         // 生产环境启用
    tokenExpiry: 3600000,  // 1小时过期
  },
  cors: {
    origins: ['https://your-domain.com'],
    methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
  },
};
```

##### 2️⃣ 指标收集系统（MetricsCollector）

**支持的指标类型**:
- **Counter**: 计数器（单调递增）
  - `http_requests_total` - HTTP请求总数
  - `calls_total` - 通话总数
  - `errors_total` - 错误总数

  - `active_connections` - 当前活跃连接数
  - `memory_usage_bytes` - 内存使用量
  
- **Histogram**: 直方图（分布统计）
  - `http_request_duration_ms` - HTTP请求延迟分布
  - `ai_llm_duration_ms` - LLM推理延迟分布
  - `ai_emotion_analysis_duration_ms` - 情感分析延迟分布
